#  CodeAlpha Python Programming Internship

This repository contains the Python projects completed as part of the **CodeAlpha Python Programming Internship**. These projects demonstrate Python fundamentals, problem-solving, file handling, automation, and user interaction through console-based applications.



#  Tasks Completed

## Task 1: Hangman Game

###  Description
A text-based Hangman game where the player guesses a randomly selected word one letter at a time. The player has six chances to guess the word correctly.

### Features
- Random word selection
- Player name validation
- Maximum of 6 incorrect guesses
- Displays guessed letters and word progress
- Prevents duplicate guesses
- Win/Lose messages
- Play again option
- Console-based application

### Concepts Used
- Functions
- Loops
- Conditional Statements
- Lists
- Sets
- Strings
- Random Module
- User Input Validation



## Task 2: Stock Portfolio Tracker

###  Description
A simple stock portfolio tracker that allows users to enter stock symbols and quantities, calculates the total investment value, displays a portfolio summary, and saves the report as a CSV or TXT file.

### Features
- Predefined stock price dictionary
- Accepts multiple stock entries
- Input validation
- Calculates total investment value
- Displays formatted portfolio summary
- Save report as CSV
- Save report as TXT
- Handles invalid inputs gracefully

### Concepts Used
- Dictionaries
- Functions
- Loops
- Exception Handling
- File Handling
- CSV Module
- User Input Validation



## Task 3: File Automation with Python

###  Description
A Python automation script that moves all `.jpg` files from a source folder to a destination folder automatically.

###  Features
- Moves all `.jpg` files
- Automatically creates destination folder
- Displays moved file names
- Shows total number of files moved
- Displays message if no image files are found
- User enters source and destination folder paths

###  Concepts Used
- File Handling
- Functions
- Loops
- Conditional Statements
- OS Module
- Shutil Module



##  Task 4: Basic Chatbot

### Description
A simple rule-based chatbot that responds to predefined user inputs through the command line.

###  Features
- Greets the user
- Responds to:
  - Hello
  - How are you
  - What is your name
  - Help
  - Bye
- Displays help for supported commands
- Handles unknown inputs gracefully
- Exits when the user types **bye**

###  Concepts Used
- Functions
- Loops
- Conditional Statements
- String Handling
- User Input/Output
